# Introdução

Este looking glass mostra as rotas **VPNv4** e **VPNv6** recebidas pelo
GoBGP a partir dos route reflectors do backbone MPLS.

## Como navegar

1. Escolha o roteador na barra lateral, em **Route Servers**.
2. Abra um vizinho para ver as rotas recebidas.
3. Use o painel de filtros à direita para restringir as rotas.

Veja também o guia de [filtros e busca](02-filtros.md).
